# Customer Segmentation & Retention Analytics (Power BI)

## 📊 Objective
To analyze customer behavior, segment users, and identify retention trends to improve business decisions.

## 🛠 Tools Used
- Power BI
- Excel
- DAX

## 📁 Dataset
Includes customer demographics, purchase behavior, engagement score, and retention status.

## ⚙️ Features
- Customer Segmentation (High / Medium / Low)
- Retention & Churn Analysis
- KPI Tracking (Revenue, AOV, Retention Rate)
- Interactive Dashboard Filters

## 📈 Key Insights
- High-value customers contribute majority of revenue
- At-risk customers identified using engagement score
- Online channel drives higher engagement

## 🚀 Conclusion
This dashboard helps businesses improve retention strategies and maximize customer lifetime value.
